# telecom-analysis-spanish
Análisis exploratorio y segmentación de clientes de ConnectaTel (planes Básico/Premium) a partir de datos demográficos y de uso (llamadas y mensajes) en Latinoamérica durante 2024. Incluye limpieza de datos, detección de outliers, segmentación por edad y nivel de uso, y recomendaciones de negocio para optimizar la oferta de planes.
